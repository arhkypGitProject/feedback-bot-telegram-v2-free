# Clearline Feedback Bot

> Стильный многоязычный Telegram-бот обратной связи с личной историей обращений, прозрачным уведомлением о конфиденциальности и защищённым рабочим пространством администрации.

## Обзор

Clearline превращает Telegram-чат в небольшую службу поддержки. Пользователь выбирает язык, создаёт обращение, просматривает полную историю переписки и получает ответы администрации в том же чате. Администраторы получают защищённую панель с открытыми обращениями, закрытыми обращениями и полным архивом.

## Возможности

- 🌍 Интерфейс на английском, русском, польском, украинском и немецком языках
- ✉️ Создание обращений через inline-кнопки и команду `/feedback`
- 🗂 Личная история обращений со всеми сообщениями пользователя и администрации
- 🛡 Панель только для администраторов с проверкой Telegram ID
- 📥 Разделы открытых, закрытых и всех обращений
- ✅ Закрытие и повторное открытие обращений из окна переписки
- 💾 Локальная SQLite-база без отдельного сервера
- 🔒 Понятное уведомление: переписка записывается, конфиденциальна и может быть просмотрена уполномоченной администрацией при необходимости
- ⌨️ Меню команд Telegram регистрируется автоматически
- 🧱 Модульные роутеры aiogram, FSM-состояния, ограничения ввода, проверки владельца и экранирование HTML

## Поддерживаемые команды

| Команда | Назначение |
| --- | --- |
| `/start` | Открыть главное меню |
| `/feedback` | Создать обращение |
| `/history` | Открыть личную историю |
| `/language` | Выбрать английский, русский, польский, украинский или немецкий |
| `/help` | Открыть локализованную помощь и правила конфиденциальности |
| `/cancel` | Выйти из текущего режима ввода |
| `/admin` | Открыть панель администратора при наличии прав |

## Пользовательский сценарий

На первом экране находится компактное inline-меню. Пользователь может создать обращение без знания команд, в любой момент сменить язык и открыть обращение для просмотра полной хронологии. Сообщения сохраняются с ролью автора и временем UTC. Пользователь видит только собственные обращения.

## Сценарий администратора

Telegram ID из `ADMIN_IDS` могут открыть админ-панель. Она разделяет текущую работу и историю:

1. **Открытые обращения** показывает запросы, требующие внимания.
2. **Закрытые обращения** показывает решённые запросы.
3. **Вся история обращений** показывает все сохранённые запросы.

Администратор может открыть обращение, посмотреть полную переписку, ответить пользователю, закрыть обращение и открыть его снова. Ответ сохраняется до попытки доставки.

## Конфиденциальность и защита

Бот сообщает, что переписка с администрацией записывается для качества сервиса и истории обращений. Переписка конфиденциальна, но уполномоченные администраторы могут просмотреть её для решения обращения. Ограничьте `ADMIN_IDS` доверенными аккаунтами.

Также применяются базовые меры защиты: проверка администратора в каждом admin-callback, проверка владельца обращения, ограничение сообщения в 4 000 символов, экранирование пользовательского HTML, локальный `.env` и исключённая из Git папка базы.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

Настройте `.env`:

```env
BOT_TOKEN=your_bot_token_from_botfather
ADMIN_IDS=123456789,987654321
DATABASE_PATH=data/feedback.sqlite3
```

Токен бота можно получить у [@BotFather](https://t.me/BotFather), а Telegram ID — у [@userinfobot](https://t.me/userinfobot). Запуск:

```powershell
.\.venv\Scripts\python.exe main.py
```
